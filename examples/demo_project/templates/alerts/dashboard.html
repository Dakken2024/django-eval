Welcome to django-eval Demo

This demo project shows how to integrate django-eval into a Django application.

Quick Start

  1. Create an alert via New Alert
  2. View the alert and click Evaluate to run it through the rule engine
  3. Check the Rules page to see active rules
  4. Use Test Rules to experiment with different contexts
  5. Manage rules in the Django Admin

Key Features Demonstrated

  • Decision Table Rules - First-hit policy with when/then conditions
  • Expression Evaluation - Safe Python expressions via SimpleEval
  • Rule Testing - Test rules with custom JSON contexts
  • Audit Logging - Custom callback for evaluation tracking
  • Django Admin - Full CRUD with inline testing panel

API Endpoints

django-eval provides a complete REST API. Try these endpoints:

Endpoint Description
GET /api/eval-engine/health Engine health check
POST /api/eval-engine/evaluate Evaluate a rule against context
GET /api/eval-engine/rules List all rules
POST /api/eval-engine/rules/validate Validate expression syntax
GET /api/eval-engine/rule-config/field-schema Available field schema
